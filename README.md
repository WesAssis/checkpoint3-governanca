Este projeto foi desenvolvido como parte de um estudo de governança, focado na arquitetura e componentes do sistema Atrium, conforme detalhado no documento "CHECKPOINT 3 - GOVERNANCA - ATRIUM.pdf".

## Visão Geral do Projeto

O projeto analisa a estrutura do sistema Atrium para gestão da inovação desenvolvido para EUROFARMA, abordando suas diversas camadas e componentes, incluindo:

* A: Visão da Arquitetura
* B: Arquitetura de Negócios
* C: Arquiteturas de Sistemas de Informação
* D: Arquitetura Tecnológica
* E: Oportunidades e Soluções

Para mais detalhes sobre a arquitetura específica e o fluxo de dados, consulte o documento "CHECKPOINT 3 - GOVERNANCA - ATRIUM.pdf".
